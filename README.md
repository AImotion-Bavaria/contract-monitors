# contract-monitors

Verified compositional runtime monitoring from assume/guarantee contracts.

- `lean/` – Lean 4 development `ContractMonitors` (no Mathlib). Build with `lake build`.
- `paper/` – LaTeX sources (Springer LNCS). Build with `latexmk -pdf main.tex`.
- `notes/` – working notes and decisions.

The toolchain version is pinned in `lean/lean-toolchain`.
